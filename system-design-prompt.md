## Project Overview

An automated daily news dashboard that includes:
- A frontend page (clean tech style, supports mock data debugging)
- GitHub Actions to fetch real API data on a schedule (API keys stored securely via Secrets)
- The frontend reads a static JSON file from the repository (no direct API calls from the browser)
- Deployed to GitHub Pages

## Architecture

### Data Flow
1. GitHub Actions runs daily on a cron schedule
2. Actions uses API keys from Secrets to call three news APIs
3. Transforms and merges the responses into a single `news.json` file
4. Commits and pushes `news.json` to the `claude_source` branch
5. Frontend page fetches `news.json` from the same directory and renders it
6. User sees the latest data when visiting GitHub Pages

### Branch Strategy
- `claude_source`: stores all source code (HTML + workflow + README) + auto-generated `news.json`
- `claude`: GitHub Pages display branch (or use `claude_source` directly as Pages source)

## GitHub Actions Workflow Requirements

### File Location

```
.github/workflows/fetch-news.yml
```

### Features

1. Scheduled trigger: daily at 8:00 AM Beijing time (cron: `0 0 * * *` UTC, which is 8:00 UTC+8, or let user adjust)
2. Manual trigger support (`workflow_dispatch`)
3. Calls three APIs using Secrets:
   - **Finance**: `https://finnhub.io/api/v1/news?category=general&token=${{ secrets.FINNHUB_KEY }}`
   - **AI**: `https://gnews.io/api/v4/search?q=artificial%20intelligence&token=${{ secrets.GNEWS_KEY }}`
   - **GitHub Trending**: `https://api.github.com/search/repositories?q=created:>{yesterday's date}&sort=stars&order=desc&per_page=10` (no key required, but can use `secrets.GITHUB_TOKEN` for higher rate limit)
4. Data transformation: maps each API response to the unified JSON structure
5. Saves and commits `news.json` to `claude_source` branch (commit message with `[skip ci]` to avoid loops)

### Security Requirements

- All API keys must use `${{ secrets.XXX }}` syntax
- No plaintext keys anywhere in workflow files
- README must explain how to add secrets in GitHub Settings:
  - `FINNHUB_KEY`
  - `GNEWS_KEY`
